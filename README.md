# Aura AI

Prompt: Build a Modern AI Productivity Assistant Website

Design and build a modern, premium, responsive AI Productivity Assistant web application that is visually appealing, intuitive, and easy to navigate. The design should prioritize simplicity, professionalism, and productivity while maintaining a polished, contemporary aesthetic.

Overall Style

The interface should feel like a premium SaaS product similar to Notion AI, ChatGPT, Linear, or Microsoft Copilot.

Color Palette

 White backgrounds

 Black typography

 Soft gray surfaces

 Elegant muted pink accent color

 Minimal use of gradients

 Plenty of whitespace

 Rounded corners

 Subtle shadows

 Smooth animations

 Modern typography

 Clean iconography

The experience should immediately communicate trust, intelligence, and efficiency.

Layout

Create a dashboard application with the following layout:

Left Sidebar Navigation

Include icons and labels for:

 Dashboard

 AI Email Generator

 AI Task Planner

 AI Assistant

 History

 Saved Work

 Settings

The sidebar should collapse on mobile.

Top Navigation Bar

Include:

 Application logo

 Search bar

 Notifications icon

 User profile/avatar

 Theme switch (Light/Dark)

Main Dashboard

Display modern statistic cards showing:

 Emails Generated

 Tasks Planned

 AI Conversations

 Productivity Score

Follow this with:

 Recent Activity

 Quick Actions

 AI Suggestions

Core Features

1. Smart Email Generator

Create an interface where users can:

Input:

 Email purpose

 Recipient

 Tone

 Context

 Additional instructions

Buttons:

 Generate

 Improve

 Rewrite

 Shorten

 Expand

Output:

Display a beautifully formatted AI-generated email.

Allow users to:

 Copy

 Edit

 Download

 Regenerate

2. AI Task Planner

Create an intelligent planning assistant.

Inputs:

 Goal

 Deadline

 Available hours

 Additional notes

AI Output:

Generate:

 Daily schedule

 Milestones

 Time estimates

 Priority breakdown

 Productivity recommendations

Display the plan inside elegant cards and timeline components.

Build a modern chatbot experience.

Include:

 Chat history

 AI responses

 Suggested prompts

 Send button

The interface should resemble a premium AI chat application.

Responsible AI Disclaimer

Display a clear notice within the application:

AI-generated content is provided for assistance purposes only. Please review, verify, and edit all generated content before using it professionally or making important decisions. AI responses may occasionally contain inaccuracies or incomplete information.

The disclaimer should be visible but unobtrusive, such as in the footer or beneath generated outputs.

Technical Requirements

 Responsive HTML5 structure

 Modern CSS (or Tailwind CSS)

 React with TypeScript preferred

 Modular, reusable components

 Clean architecture

 Accessible design (WCAG compliant where practical)

 Fast loading performance

 Dark mode support

 Easy integration with AI APIs (e.g., OpenAI-compatible endpoints)
